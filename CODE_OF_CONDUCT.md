# Code of Conduct

`openmcphub` adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct, in full and without modification.

The canonical text is hosted at the link above. We adopt it by reference rather than vendoring the file so that we automatically inherit any errata or clarifying language the upstream maintainers publish.

## Scope

This code applies in all `openmcphub` spaces — issue trackers, pull requests, discussions, code review, commit messages, release notes — and in any public communication where someone is acting as an `openmcphub` contributor or maintainer.

## Reporting

If you experience or witness behavior that violates the code, contact the maintainer directly at:

**`wilevergomez@gmail.com`** — subject line `[openmcphub] Conduct report`.

Reports are confidential. We will acknowledge receipt within 72 hours and respond with next steps within seven days. Reporters will not face retaliation for filing a good-faith report.

## Enforcement

The maintainer is responsible for enforcement and will follow the four-tier enforcement ladder defined in the Contributor Covenant 2.1 (Correction → Warning → Temporary Ban → Permanent Ban).
